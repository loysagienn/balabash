# Balabash

The source code of Balabash, a personal self-hosted assistant — the system
the agents of this installation run inside.

- `README.md` — what Balabash is and what it does.
- `SETUP.md` — what an installation needs, how it is configured, started and run.
- `DEVELOPMENT.md` — working on this code: the map of the repository and the
  rules of changing a live system. Read it before changing anything here.
