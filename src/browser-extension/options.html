Blocked sites

One site per line, for example bank.example.com. An entry covers its subdomains. The agent cannot open these sites, does not see their tabs and cannot take them; a tab of the agent that ends up on one is taken from it. A blocked site shown inside a frame of another page is not caught.

List of tabs

Without the list the agent still works in its own tabs and in the ones you hand to it.

Handing tabs over

When the agent asks for one of your tabs, a window asks you first. With this on there is no window: the agent takes any tab it asks for, except the tabs of blocked sites.
